Important feature limitations

  • No trained YOLO weights or labelled dataset are included. OpenCV output is an untrained heuristic and must always be manually reviewed.
  • OCR was tested only on a clean generated number-plate image; real-world image accuracy is not established.
  • Video upload and video smoke analysis are not implemented; current AI upload accepts still images.
  • Nearby police station lookup uses administrator-configured station records only. No live official station provider is connected.
  • Demo complaint records and accounts are fictional. Do not use demo credentials in production.
